# Suggested commands (react-layout-kit)

From `package.json` scripts:

- Build library (clean + compile + path alias rewrite):
  - `npm run build`

- Dev/watch build:
  - `npm run dev`

- Typecheck only:
  - `npm run check`

- “Test” (actually builds):
  - `npm test`

- Storybook (local):
  - `npm run storybook`

- Build Storybook static output:
  - `npm run build-storybook`
